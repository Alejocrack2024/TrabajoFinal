# Sistema de Inventario - Django

# Inicio Rápido

# Prerrequisitos
- Docker
- Docker Compose

# Decargar repo:
git clone https://github.com/Alejocrack2024/TrabajoFinal
```
levantar solo comando :
cd inventario
crear imagen contenedor:
docker compose build
correr contenedor:
docker compose up -d
desde django:
python manage.py runserver
```

# Acceso:
Aplicación: http://localhost:8000
Panel Admin: http://localhost:8000/admin

El sistema estará ejecutándose en http://localhost:8000
